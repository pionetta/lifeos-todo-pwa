# Visual Design System (Soft Bento Pastel Style)

## 1. Style & Foundations
- Layout Concept: Soft Bento Grid (2-column modular cards & wide highlight cards).
- Corner Radius: 
  - Cards & Containers: `rounded-3xl` (24px)
  - Small badges & buttons: `rounded-full`
  - Floating Bottom Bar: `rounded-full`
- Background: Clean warm white `#FBFBFD` / `#F6F7FB`.
- Typography: Sans-serif (Inter / Plus Jakarta Sans), large bold numbers for metrics (e.g. 95%, 62.5).

## 2. Bento Pastel Palette
- Hero Highlight Card (Lavender/Periwinkle):
  - Background: `#D7D9FE` (Soft Iris)
  - Text & Accents: `#3538CD` / Slate 900
- Daily Task / Wins Card (Pastel Peach/Coral):
  - Background: `#FCE4DE` (Warm Coral)
  - Action button: White circle with dark icon
- Category Card A (Soft Amber/Cream):
  - Background: `#FDEFD9`
- Category Card B (Soft Blue/Ice):
  - Background: `#D9E8FD`
- Category Card C (Soft Mint/Teal):
  - Background: `#D5F2EB`
- Category Card D (Soft Red/Rose):
  - Background: `#FEDCDC`
- Dark Action Elements: Slate 900 `#18181B` (untuk tab aktif atau pill CTA seperti 'Get Started').

## 3. UI Patterns Reference
- Top App Bar:
  - Profil avatar bulat + sapaan teks bold ("Hello, [Nama]!")
  - Search icon & Bell icon di kanan dengan background bulat putih.
- Hero Progress Card:
  - Big bold percentage (misal: "85%" Target Harian).
  - Circular SVG progress ring / badge di sebelah kanan.
- Bento 2-Column Cards (Wishlist & Scope To-Do):
  - Judul modul + mini icon badge di pojok kanan atas.
  - Subtitle ringkas.
  - Tautan bawah: teks "Check" + tanda panah kanan (`→`).
- Floating Bottom Navigation:
  - Rounded-full pill mengambang di tengah bawah.
  - Background putih solid/transparan dengan subtle drop shadow.
  - Ikon aktif berwarna gelap (Slate 900) dengan indikator titik/lingkaran halus.
